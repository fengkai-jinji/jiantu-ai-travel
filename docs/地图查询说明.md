# 本地地图查询

在项目目录运行 `启动项目.ps1`，会启动前端 5173、YOLO 8765、地图服务 8766。脚本使用本机已有 Node 和 yolo Python 环境，其他电脑需调整路径并安装项目依赖。

网页选择出行助手：填写城市后，出发地/目的地输入框即输即搜（≥2 个字、停顿 450ms 触发），下拉展示高德候选，鼠标点选或键盘 ↑↓ + Enter 确认（Esc 关闭）；两端确认后点「查询步行路线」。

交互规则：手动修改已确认的地点会清除确认状态并提示重新点选，此时提交只提示、不用旧坐标算路；修改城市会重置两端。计划出发时间改为预设选项（尽快/今天上午等）+「自定义时间」展开日期时间控件；时间与偏好暂不参与算路。

密钥放在项目 `.env` 的 `AMAP_MAPS_API_KEY` 中；不加 `VITE_` 前缀，不提交公开仓库。地图服务每次请求读取配置，无须因修改 Key 重启。后端不记录查询内容和密钥，响应不缓存。

当前能力：高德同城地点搜索（输入即搜下拉）、候选确认、普通步行路线、估算距离/耗时、逐段文字路线、来源与查询时间、通用核实清单、浏览器朗读。

边界：尚未接大模型，不是自主 Agent；不查询公交；出发时间、偏好和备注不参与算路，不传给高德；未核实无障碍设施；不是实时避障导航。即输即搜会增加地点搜索调用次数（每次输入停顿一次），注意高德配额。

接口：`POST /trip-api/places` 接收 city、keywords；`POST /trip-api/walking` 接收 origin、destination（高德 GCJ-02 坐标）。Vite 代理至本机 Python 服务，密钥只由服务端发送至高德官方域名。

验证：TypeScript/生产构建通过；检测测试 2 项、地图适配测试 4 项通过。2026-11-02 浏览器验收：即输即搜下拉（真实高德候选）、键盘 ↑↓/Enter 选择（合成事件验证，自动化环境按键注入受限）、鼠标点选、确认/改字清空/提交拦截、无结果提示（乱码关键词）、路线查询（三江学院 → 茂业天地 9.44 公里 24 段）、清单勾选、朗读/停止。

高德官方文档：https://lbs.amap.com/api/webservice/guide/api/direction
