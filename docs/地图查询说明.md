# 地图与出行助手说明（提交版）

更新：2026-11-14。当前安装和启动方式以 [运行与交付说明](运行与交付说明.md) 为准。

## 当前能力

页面使用城市与地点关键词搜索高德候选，由用户点选确认起点和终点，再比较步行、公交、地铁及混合方案。是否出现某种方案取决于高德返回和当前解析规则，不能保证任意查询都包含地铁。地点编辑后需重新确认，不能继续拿旧坐标算路；普通对话应保留已有有效方案。

Agent 支持地点搜索、周边搜索、路线比较和知识检索四种工具。部分明确的周边餐饮、小吃请求直接走地图查询，其余请求由模型选择工具或补问。SSE 用实际事件显示请求、工具与回答状态；不展示模型内部推理。附近结果中的直线距离不是步行路程。

路线排序依据当前偏好与交通段信息，由确定规则完成。出发时间与具体路线参数是否生效应以当前接口实现与返回字段为准，不将用户备注直接理解为地图已经核实的设施条件。地图方案不能证明盲道、电梯、台阶或临时障碍的状态。

## 配置和端口

高德密钥填写到本机 `.env` 的 `AMAP_MAPS_API_KEY`，不要加 `VITE_` 前缀。大模型使用 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。真实配置不入库、不打包。地图与 Agent 在 8766，前端 5173 经 `/trip-api` 代理访问。

接口包含 `/trip-api/status`、`places`、`walking`、`compare`、`chat`、`chat-stream` 和 `kb`。状态接口的 configured 只表示配置存在，不代表外部 API 当次调用成功。地图调用受网络、有效 Key 与配额约束。
