## 三、全站视觉方向

沿用见途绿色、米白、暖金与已有品牌识别。方向是有空间感的温暖技术产品：真实3D几何、清晰字阶、前后层次、柔和光影、克制材质，而不是霓虹控制台或纯营销模板。

## 四、逐页实施要求

3. 四项能力区：出行助手、室外感知、室内寻物、无障碍知识，分别展示它们不同的使用情境与入口。
4. 真实能力展示：可呈现实际路线卡、来源卡或模型结果的设计说明；若截图含测试数据须标明，不能假装实时数据。

### 3. 环境感知：3D街区与真实画面之间有完整状态

保留 `SpatialStage` 真实Three.js街区，不能退化成大图轻微倾斜。待机时可环视、正面、聚焦；上传/摄像头开始后切回真实画面。

画面附近清楚提供：摄像头、停止、照片输入、当前状态。结果侧栏保留：当前目标、单帧/实时采样、连续确认、画面方位、置信度、提示依据与语音控制。将主要结果放在首屏可理解的位置，技术判据可放“查看提示依据”详情，不能一进来像调试面板。

必须覆盖：等待输入、等待权限、处理中、收到结果、没有检出、权限拒绝、服务失败、停止、WebGL回退。空状态说明怎样开始，错误状态给可执行恢复操作。

当前已修正的规则必须保留：
- 照片是单帧，实时按类别与画面方位做相邻两帧确认；不是实体追踪。不能把同一帧两个同类框当成两帧。
- 二维框级别不等于准确米数，不能再显示“约1米内”等未标定距离。
- “画面边缘”不是路线外或车辆停放，不能据此静默近级车辆。
- 所有服务返回框保留真实坐标，不通过动画移动/补造目标；原服务远目标过滤仍存在，不能宣称全目标无遗漏。
- 同一危险播报未结束不能不断取消自身；只有新危险的抢占策略按既有实现执行。自动播报可随时关闭，文本始终可读。

这些是观察提醒，不是过马路指令或安全保证。3D模型和示意标记必须标为示意。

### 4. 室内寻物：围绕目标的空间操作体验

处理目标切换、取消、权限错误、无目标、失败与重试时状态连贯，旧请求不得写入新目标结果。操作在手机上可触达，不能靠鼠标悬停才能使用。

### 5. 无障碍问答：完整知识产品，不是一个空聊天框

## 五、动态是默认主表现，减少动态是开关

这是用户反复确认的关键要求，不要再次做成默认静态网页。

| 场景 | 正常模式 | 减少动态 |
| --- | --- | --- |
| 进入页面 | 内容分层入场、节奏清楚，不挡操作 | 完整内容立即出现 |
| 3D待机 | 软光、阴影、缓慢运镜、轻微视差、标记浮动 | 静态3D，视角按钮直接切换 |
| 视角与目标切换 | 镜头平滑过渡，焦点明确 | 直接到位 |
| 方案选择 | Flip布局与详情展开，数字/节点协调 | 直接呈现选中方案 |
| Agent与资料结果 | 真实数据到达后短距离入场，流式内容及时显示 | 内容照常到达，不做装饰运动 |
| 请求等待 | 真实状态配合柔和反馈 | 保留状态文字和取消入口 |

站内与系统减少动态均需生效，开关时立即停止非必要JS动画而不是只加CSS。不要因“面向老年人/视障”就让默认模式变素。不要全站强制滚动劫持、大幅旋转或遮罩转场。

使用已安装的GSAP/Three，不为单一效果堆新库。重用现有材质、图标与组件；同一个transform只有一个动画所有者。卸载、切目标、开关偏好时清理RAF、订阅、监听、GSAP context和GPU资源；后台和视口外停止装饰渲染。真实检测画布保持原比例和坐标。
