# 审美学习笔记 → 见途四轮升级依据

学习对象：Stripe / Linear（公认高级感）+ Awwwards 2025-26 趋势（去扁平化：玻璃拟态、Bento、质感与微动效）。

## 提炼的七条高级感规律 → 在见途的落点

1. **排版是第一高级感**：克制字阶、精调字距、标题有呼吸感 → Round2 整理 eyebrow 字距、标题行高、面板内距节奏。
2. **留白节奏**：慷慨且一致的间距 → Round2 Bento 布局重排首页卡片，统一 gap。
3. **克制配色 + 一处点睛**：色板有限、琥珀只做点睛 → 全轮遵守（描边光带用琥珀 #e8bd66，其余深绿系）。
4. **质感取代扁平**（2025-26 趋势）：柔光渐变、点阵纹理、分层阴影 → Round3 点阵底纹 + Spotlight 追光。
5. **微交互无处不在**：数字滚动、描边流动、按钮流光 → Round1 数字滚动+流动描边、Round4 Shimmer 按钮。
6. **SVG 而非位图**：缩放清晰体积小 → 沿用现有 RouteScene/城市舞台 SVG 路线，不引位图。
7. **工艺胜过模仿**：每个细节迭代打磨 → 每轮构建+截图检查，不满意就再调。
