# 见途知识库说明

更新日期：2026-11-13。按server/kb.py和knowledge.json核对。

五个主题分别是帮助方法、视障与无障碍认知、设施交通、陪同出行、景点出游。当前22条资料，其中5条字段标记verified=true、17条待核验；这些是维护者标记，不是本轮对所有外部原文和时效逐条重新核实的结果。

检索按关键词命中、中文二元字词重叠和主题加分排序，默认取前3条；主题是加分而非硬过滤。当前没有向量数据库或语义嵌入，不宣称已实现混合向量检索。

条目字段：id、topics、keywords、title、publisher、url、date、region、summary、verified。摘要应可由具体原文支持；核验前不能把verified改true。无法确认资料应补证、修正或剔除，而不是为了展示凑数量。

无命中时程序直接拒答，不调用模型；有资料但未配置模型时显示来源摘要；已配置时只把资料作为数据交给模型生成。系统提示要求未核验资料不能支持当前开放、预约、价格和设施运行状态等确定断言。模型仍可能出错，来源标注不等于逐句事实验证。

前端保留五主题独立会话，追问仅带当前主题最近三轮。支持取消、35秒超时、旧请求隔离、失败保留已有结果、文内来源定位及朗读。离页/刷新不永久保存该页会话。

更新流程：先核对发布机构、具体链接、适用地区、资料日期及摘要，再记录核验；实时设施状态须向运营方或现场另行确认。真实Key仅配置在.env，不写进知识库。
